# 民大校园博客项目

基于 Halo 博客系统开发的校园主题博客，主打砖红色校园风格，实现个性化首页、评论区、导航栏、Logo、页脚等定制化功能。

---

## 项目信息
- **项目名称**：民大校园博客
- **开发框架**：Halo 2.x
- **主题风格**：砖红色校园主题
- **访问地址**：http://111.229.210.162:8090
