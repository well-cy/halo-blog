# DeepSeek API 接口调用说明

## 1. 基础信息
- 接口地址：`https://api.deepseek.com/v1/chat/completions`
- 请求方式：`POST`
- 认证方式：`Bearer Token`
- 数据格式：`application/json`

## 2. 请求头
| 字段名 | 值 |
|--------|----|
| Authorization | `Bearer {你的API_KEY}` |
| Content-Type | `application/json` |

## 3. 请求参数
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| model | string | 是 | 模型名，如 `deepseek-chat` |
| messages | array | 是 | 对话消息数组 |
| temperature | number | 否 | 温度系数，0~1，默认 0.7 |
| max_tokens | int | 否 | 最大生成长度 |
| stream | bool | 否 | 是否流式返回，默认 false |

## 4. 响应示例（简化）
```json
{
  "id": "xxx",
  "object": "chat.completion",
  "created": 1234567890,
  "model": "deepseek-chat",
  "choices": [
    {
      "index": 0,
      "message": { "role": "assistant", "content": "返回的内容" }
    }
  ]
}
---

# 搜索功能调研与设计文档（新增）

## 1. 调研背景
校园博客文章数量增多，用户需要通过关键词快速定位内容，因此开发站内搜索功能。

## 2. 需求分析
### 2.1 用户需求
- 支持按文章标题/正文关键词搜索
- 搜索结果带**预计阅读时间**标签
- 关键词高亮显示，方便快速定位
- 无搜索结果时显示友好提示
- 点击结果可直接跳转到真实文章

### 2.2 功能目标
- 搜索响应速度≤1秒
- 结果优先匹配标题，其次匹配正文
- 交互友好：支持回车触发、失焦关闭弹窗

## 3. 竞品参考
参考主流博客站内搜索设计：
- 搜索框固定在页面顶部右侧，不遮挡内容
- 结果以弹窗形式展示，包含标题、摘要和附加信息
- 支持关键词高亮和阅读时间等辅助信息

## 4. 技术方案（Halo博客）
### 4.1 实现思路
- 前端：通过`inject-code.html`注入搜索框、弹窗样式和交互逻辑
- 数据：使用文章列表模拟真实数据，结果跳转`/archives/文章slug`地址
- 附加功能：为文章卡片和搜索结果添加阅读时间标签

### 4.2 核心功能点
1. 顶部右侧固定搜索框（含搜索图标）
2. 回车触发搜索，弹窗展示结果
3. 结果含标题、摘要、灰色阅读时间标签
4. 关键词高亮显示
5. 无结果友好提示：“暂无搜索结果，换个关键词试试吧”
6. 点击标题跳转真实文章

## 5. 验收标准
- ✅ 搜索框正常显示，回车可触发搜索
- ✅ 结果带阅读时间标签，关键词高亮
- ✅ 无结果时显示友好提示
- ✅ 点击标题可跳转真实文章
- ✅ 交互流畅，弹窗可关闭

## 6. 总结
本次调研明确了站内搜索的需求与实现方案，采用前端注入方式快速落地，既满足用户快速找文章的需求，也符合校园博客的整体风格。
