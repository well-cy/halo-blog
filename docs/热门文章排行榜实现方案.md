# 热门文章排行榜实现方案

## 一、功能概述
实现校园博客首页「热门文章排行榜」侧边栏功能，根据文章访问量、点赞量、发布时间综合排序，展示阅读量高、受欢迎的文章，提升用户阅读体验与页面活跃度。

## 二、实现目标
1. 在博客首页右侧展示 **热门文章 TOP 10**
2. 文章排序规则：访问量权重最高 + 点赞量辅助排序
3. 样式与校园主题统一，简洁美观，不影响页面布局
4. 支持自动刷新，无需手动配置

## 三、技术方案
### 1. 排序规则（优先级从高到低）
1. 文章访问次数（核心权重）
2. 文章点赞数量
3. 最新发布时间

### 2. 前端展示
- 展示位置：首页右侧 sidebar 热门文章区域
- 展示内容：文章标题 + 分类标签 + 阅读量
- 样式：圆角卡片、hover 动效、分类彩色标签
- 数量：默认展示前 10 条

### 3. 后端逻辑（Halo 博客适配）
基于 Halo 系统原生文章数据：
- 获取 `posts` 列表
- 按 `visits` 访问量降序排列
- 排除草稿、私密文章
- 限制返回数量为 10

### 4. 样式规范
- 继承博客砖红色主题配色
- 分类标签使用统一彩色：
  - 活动资讯：蓝色
  - 日常生活：绿色
  - 学习笔记：黄色
  - 校园新闻：红色
  - 社团动态：紫色

## 四、实现步骤
1. 获取博客文章列表并按访问量排序
2. 筛选公开、已发布文章
3. 前端渲染排行榜列表
4. 添加分类彩色标签样式
5. 优化 hover 交互与响应式布局

## 五、效果说明
- 打开首页即可看到右侧「热门文章排行榜」
- 点击文章标题可直接跳转对应文章
- 分类标签彩色显示，与首页文章卡片样式保持统一
- 排行榜自动更新，无需后台配置

## 六、兼容性
- 适配 PC 端、平板端
- 移动端自动隐藏（不影响布局）
- 兼容所有主流浏览器
- 不影响原有功能运行

## 七、维护说明
- 无需数据库操作
- 无需插件依赖
- 基于原生主题样式扩展
- 后续可扩展：按周热门、总热门切换
